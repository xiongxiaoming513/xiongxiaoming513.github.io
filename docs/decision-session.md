# 决策 Session（个人写作版）

> 用途：把"今天写什么"这个每天消耗注意力的决定，压缩成 **1 分钟**。
> 这是 90 天路线图阶段 5 里"决策 Session"的个人版：不管理团队，只管理自己的选题。

## 它解决什么问题

写作最常见的卡点不是写不出来，而是：

1. **不知道写什么**——打开编辑器，光标闪了十分钟
2. **想写的太多**——三四个念头打架，最后一个都没写
3. **想写又觉得不够好**——"这个观点太普通了"，于是放弃

这三个问题本质是同一个：**你在用写作的时间做选题决策。** 把决策单独拿出来，写作时就不必再想。

## 每天一句

固定在晚上（或第二天早上），只问一句：

> **现在有什么值得我写的？**

## Prompt（复制即用）

```text
你是我的选题过滤器，不是写作助手。

基于以下材料，只给我 3 个值得写的选题，不要更多：
- 我已发布的文章标题与摘要（读取 content-lock.json 或 /blog/ 页面）
- 我的草稿箱（如果有 draft: true 的文章）
- 本周提交记录（git log 最近 7 天）
- 我最近反复想到的问题（我会在下面补充）

对每个选题，给出：
1. 一句话角度（不是标题，是"我想说什么"）
2. 为什么是现在写，而不是下个月
3. 素材从哪里来（经历 / 数据 / 读过的书 / 踩过的坑）
4. 预计长度（300 字 / 800 字 / 1500 字）
5. 最大的风险（可能写不下去的地方）

最后只推荐 1 个，并说明：如果今天只能写 200 字，写哪一段。

规则：
- 能一句话说清的不写成长文
- 追热点必须有独特角度 + 一手经验，否则不写
- 已发布过的主题不重复，除非有新证据
- 不确定的不要硬凑，宁可说"这周没有值得写的"
```

## 三条过滤规则（比 prompt 更重要）

| 规则 | 判断标准 | 反例 |
| --- | --- | --- |
| **能一句话说清的不写长文** | 核心观点 ≤ 25 字 | 把一个常识扩写成 2000 字 |
| **热点必须有独家角度** | 有一手经历或数据 | "AI 又发布了新模型，我谈谈看法" |
| **旧题要有新证据** | 有推翻/补充 | 换个措辞重写半年前的观点 |

## 每周一次（周日，配合周报）

周报（`docs/weekly-log.md`）自动生成后，花 5 分钟：

1. 本周的提交里，有没有值得展开成文章的？
2. 草稿箱里有没有该删掉的？
3. 给下周定 **1 个必写选题**，写进 `docs/idea-log.md`

## 选题池

见 [`docs/idea-log.md`](idea-log.md)：一句话选题 + 状态（未写 / 在写 / 已发 / 放弃）。

三个月后回看这个表会很有价值——你会发现哪些选题一直没写，以及原因通常是"其实没那么想说"，而不是"没时间"。

## 一个提醒

决策 Session 的目的是**减少内耗**，不是增加一个待办。

如果某天它给出的三个选题你都不想写，那就说明今天不该写——去做别的，别硬凑一篇。
